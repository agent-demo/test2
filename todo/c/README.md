# Toradora — C

The original terminal implementation uses SQLite and is built with the repository's root Makefile.

```bash
make
./todo/c/toradora -h
```

It supports adding, prioritising, editing, completing, and listing tasks. The original `-d` option creates an always-visible daily task. See the [main README](../../README.md) for the contribution workflow.
